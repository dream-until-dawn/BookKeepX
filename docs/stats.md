# P1-9 统计展示

## 范围与口径

提供独立统计页：所选月份的收入、原始支出、退款、净支出、结余；分类构成；每日趋势；截至所选月的连续 12 个月趋势。沿用 P0-2 探针，全部在服务端 SQL 聚合，不向前端传原始流水；不增加数据表。

- 账本时区决定月/日边界；月份包含起点、不包含下月起点。空日、空月补零。
- 删除的记录、标记为跨来源重复的记录不计。普通中性记录不计；退款不论原方向均冲减支出，不计收入。
- 退款按退款发生时间冲减**原消费当前分类**，即使原消费在别的月份或已软删除。没有原消费或原消费未分类时归入「其他支出」。隐藏分类仍参与统计，普通未分类收支单独展示。
- 分类默认汇总到一级，收入与净支出分别展示。分类合计、每日合计与月度汇总保持一致。
- 净支出为负是有效结果，不截成零。分类全部非负且合计大于零时展示饼图和占比；出现负分类时展示有正负轴的条形图，表格保留金额并提示不计算占比。
- 金额全程整数分；聚合值、结余超出 JS 安全整数范围时返回明确错误，不静默截断或丢精度。

## 接口与实现

`GET /api/ledgers/:ledgerId/stats?month=YYYY-MM`，viewer 及以上可读。月份必填，范围 1901-01 至 9998-12，非法或额外字段返回 400；非成员返回 404。

返回 month、timezone、summary、categories（group/categoryId/name/incomeCents/grossExpenseCents/refundCents/expenseCents）、daily、monthly。所有金额为整数分，结余 = 收入 - 净支出。月度、分类、日趋势在同一 repeatable-read 事务中读取，避免并发导入导致同一响应中各部分不一致。

服务端划分 routes → service → repository；前端 features/stats 包含数据请求、纯图表配置与生命周期组件。统计路由惰性加载，ECharts 使用 core + 折线/柱状/饼图 + SVG renderer 按需注册。图表提供文本表格替代、空数据提示；容器尺寸变化时 resize，卸载 dispose。

## 验证计划

真实 PostgreSQL 覆盖金额、北京时间跨月、夏令时时区、闰年空日补齐、跨年趋势、退款分类、负净支出、未分类、隐藏分类、去重删除中性排除、用户隔离、viewer 可读、非法月份、聚合溢出。界面验证月份切换、错误状态、空状态、负数展示与图表配置；故意改坏退款、时区边界或重复过滤，确认测试变红后恢复。构建检查统计页及图表分包。
