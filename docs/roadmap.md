## P1 MVP（目标 tag：`v0.1.0`）

按依赖顺序，每项一个 feature 分支：

1. `core/money`：金额解析与格式化（先写正反向测试）
2. 数据库 schema + 迁移 + 默认分类种子
3. 鉴权：注册 / 登录 / 登出 / 会话
4. 分类与资金账户管理
5. 手动记账：增删改查、列表筛选
6. 导入管线：通用引擎 + 内置模板（微信 / 支付宝 / 招行 PDF）+ 自动识别；自校验门槛、预览、同来源 / 跨来源去重、整批撤销
7. 自定义解析模板：识别失败时的列映射向导，保存为用户模板
8. 分类体系：预置分类、系统规则、用户规则管理、"从修改中学习"、应用到历史
9. 统计：月度汇总、分类占比、趋势
10. 前端各页面 + PWA 清单
11. Docker 生产镜像 + 部署文档
12. E2E：注册 → 记一笔 → 导入 → 看统计 全链路

## P2 体验与移动端

Capacitor 打包、离线记账与同步、预算、标签、数据导出 / 备份。

## P3 记账 agent

自然语言记账（"午饭 32"）、导入时自动分类、消费分析问答、异常消费提醒。
