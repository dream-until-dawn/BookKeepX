# P1-10 PWA 与移动端

## 范围与设计

本阶段提供可安装的应用清单、图标、安装提示、更新提示和移动端布局。离线记账仍属于 P2：不缓存账单接口、不保存离线草稿、不做后台重试或同步。用户断网时显示提示；重新打开应用遇到断网则显示独立的离线说明页，不伪装登录成功或保存成功。

采用 `vite-plugin-pwa` 的 injectManifest 模式，Service Worker 独立在 `src/pwa/sw.ts`。只预缓存构建时列出的公共 JS/CSS、图标和离线页；HTML 导航走网络，失败回退离线页；`/api` 请求显式仅走网络且 `cache: no-store`。没有账单内容进入 Cache Storage。开发模式不注册 SW，生产构建在 HTTPS 或 localhost 下注册，避免开发热更新与旧缓存相互影响。

更新使用 prompt 模式：新版本等待用户选择「刷新更新」；提示先保存输入，不自动 skipWaiting。安装按钮只在浏览器发出安装事件后出现，拒绝或安装失败会正常收起/提示；不支持事件的浏览器提供手动安装说明。已独立运行时隐藏安装入口。断网提示独立于是否安装。

清单使用中文名称、standalone 显示、固定 id/start_url/scope，提供普通 192/512 PNG、maskable 512 PNG、Apple 180 PNG 和 SVG favicon。图形保留在 SVG 源文件中；maskable 图形位于中央安全区。移动端使用可折叠菜单、44px 触控目标、16px 表单文字、安全区内边距；表格局部横向滚动而不撑宽页面。

## 验证

- 单元/交互：安装接受与拒绝、事件监听清理、已安装状态、更新推迟与确认、更新失败、离线切换；缓存路由不匹配 API，离线 fallback 只针对导航。
- 生产浏览器：清单与图标尺寸、SW 安装/控制、缓存仅含静态资源、断网导航、API 不回退 HTML、离线 POST 不重放、新旧构建更新需要确认、移动端页面及菜单。
- 故意破坏缓存边界与主动更新约束，确认反向断言失败。完整格式、类型、测试、构建及 CI 门禁。

## 部署约定

生产必须 HTTPS（localhost 仅供测试），应用部署在站点根路径。`sw.js`、清单和入口 HTML 应重新验证缓存，带内容哈希的 assets 可长期缓存；API 使用 no-store，SPA 导航由服务端返回入口。P1-11 落实容器与反向代理配置。发布时保留旧版 assets 一段时间，避免用户推迟更新期间懒加载旧文件失败。

## 本阶段验收记录（2026-09-29）

- 新增 14 项测试，覆盖安装接受/拒绝/失败、已安装状态、离线切换、事件清理、用户确认更新，以及实际 SW 的路由优先级、API 导航不回退 HTML、缺失离线页、显式激活消息。
- 三处独立变异均被杀死：API 前缀错误匹配、API 导航错误返回离线页、新版本到达就自动更新。每处都确认变异生效并因行为断言失败，不把环境错误当成测试有效。
- Edge 无头浏览器运行生产预览（4173）：清单与 PNG 尺寸正确；SW 控制页面；Cache Storage 中仅有 12 个公共资源键，无入口 HTML 和 API；离线 GET/POST 均失败，导航显示离线说明，恢复联网未重放请求。
- 修改构建产物触发真正 SW 更新：等待及「稍后」保留输入；确认刷新当前页；另一个标签页的输入保留，并可自行确认更新。验证时发现插件对外部更新的事件标记不能覆盖全部情况，改用原生 controllerchange 判断控制器替换，首次接管不刷新。探针结束恢复构建产物。
- 合成账户验收流水、导入、分类、规则、账户、统计导航，在 320/390px 下无整页横向溢出，菜单选择后收起；无页面脚本异常。合成账户和交易验收后清理。
- 类型检查、生产构建与迁移漂移检查通过；无数据表变更。构建保留既有大包提示，另有插件内部 inlineDynamicImports 弃用提示，均未阻断构建。
- 尚未在实体 iPhone/Android 上执行系统安装；浏览器安装事件交互已测试，真实系统安装和 HTTPS 部署后复核列入发布验收，不声称已完成真机验证。

本地复核：先启动服务端，再执行 `pnpm --filter @bookkeepx/web build` 与 `pnpm --filter @bookkeepx/web preview --host 127.0.0.1 --port 4173`。开发端口 5173 不注册 SW；验证安装与离线行为请使用生产预览。请用独立浏览器上下文验证，避免影响日常登录状态；不同端口的 SW/Cache Storage 独立，但同一主机的 Cookie 不按端口隔离。
